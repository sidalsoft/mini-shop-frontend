# 🛒 Mini Shop Frontend (React)

Фронтенд часть интернет-магазина, реализованная на **React + TypeScript**.
Обеспечивает пользовательский интерфейс для работы с товарами, корзиной, заказами и админ-панелью.

---

# 🚀 Запуск

```bash
docker-compose up --build
```

---

## 🌐 Доступ

* Приложение: http://localhost:3000

---

# 🎯 Возможности

## 👤 Аутентификация

* Регистрация и вход
* Хранение JWT
* Определение роли пользователя (USER / ADMIN)

---

## 🛍️ Товары

* Список товаров
* Фильтрация:

  * по названию
  * по категории
  * по цене
* Отображение:

  * изображения
  * цены
  * описания
  * даты создания
* Бейдж **"Новинка"**

---

## 🛒 Корзина

* Добавление / удаление товаров
* Изменение количества (+ / -)
* Пересчёт общей стоимости
* Optimistic UI (мгновенное обновление)

---

## 📦 Заказы

* Оформление заказа:

  * имя
  * телефон (валидация)
  * адрес
* История заказов
* Отображение статуса
* Дата заказа

---

## ⚙️ Админ-панель

* Управление товарами:

  * создание
  * редактирование
  * удаление
* Управление категориями
* Валидация форм

---

## 🌍 i18n

* Поддержка:

  * 🇷🇺 Русский
  * 🇺🇸 English
* Переключение языка (dropdown)
* Перевод UI и ошибок

---

# 🧱 Технологии

* React (Hooks)
* TypeScript
* Redux Toolkit
* React Router
* Axios
* TailwindCSS
* i18next

---

# 📂 Структура проекта

```
src/
 ├── app/            # Redux store
 ├── features/       # бизнес-логика (auth, cart, product, order)
 ├── pages/          # страницы (Products, Cart, Orders, Admin)
 ├── shared/         # общие компоненты (UI, LanguageSwitcher)
 ├── i18n/           # переводы
```

---

# ⚙️ Конфигурация

API URL задаётся через переменные окружения:

```env
VITE_API_URL=http://localhost:8080/api
```

Использование в коде:

```ts
baseURL: import.meta.env.VITE_API_URL
```
